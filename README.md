# 🎞️ Bilheteria Virtual 
 ## Projeto de uma bilheteria virtual de cinema
 Nesse projeto coloquei em prática alguns conceitos importantes e reforcei meus aprendizados, explorando:
* Dicionários
* Listas
* Estruturas condicionais: if, elif e else
* Estruturas de repetição: while e for
* Estrutura match/case
* Funções
* Métodos de string
* Pacotes e módulos
---
A bilheteria virtual conta com um menu principal, em que o usuário tem as opções de: realizar cadastros, realizar o login, analisar as estatísticas dos cadastros e sair.

O cadastro é constituído de funções que fazem as verificações dos dados de entrada. No momento são verificações simples, com conceitos aprendidos, mas aprimorará para verificações mais complexas futuramente.

Assim que o login for realizado com sucesso, são apresentadas mais opções como: visualizar as informações de cadastro, comprar o bilhete, verificar os bilhetes já adquiridos e voltar para o menu principal.

Atualmente, estou trabalhando na parte das estatísticas, além de estar pesquisando sobre modularização para aplicar aqui. 

Conforme meu aprendizado evoluir, o programa será atualizado! 😊
